# 19: Pilot transfer checks and measurements

**What to build:** Each tester takes an independent check at the start and end of the pilot on the two pilot items, with the order swapped between testers. A script computes the pilot measurements from app data.

**Blocked by:** 16 Recommendations and Home; 18 Full content set

**Status:** ready-for-agent

Spec: `../spec.md`

- [ ] Order assignment alternates between testers and is recorded
- [ ] Start check offered at the first session after the first challenge; end check offered after the pilot end date
- [ ] Script reports: first-challenge completion, time to first review, return within 7 days, start vs end check scores, replay and hint trend, problem reports per item
- [ ] Script output contains no personal data; no third-party analytics
