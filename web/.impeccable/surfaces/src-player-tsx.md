# Browse and item player (ticket 07)

Scope: Operate. Learner Browse (items by difficulty tier) and the item player shell (reading time, map, question list, first listen). App-wide tokens (header, buttons, panels) follow this world. Phone first (360 to 430 px), desktop second. Arabic RTL frame; English content LTR.

Audience and job: adult Arabic-speaking testers pick an item and do the first listen; they must always know where they are and what the audio is doing. Anti-goals: game mechanics, red timers, travel costume (planes, gates), cute.

## Direction contract

THESIS: each item is a pass for one guided journey; identity lives on a night-teal stub, the work on light pass stock. Refuses the rounded-card study-app default.
OWN-WORLD: night-teal #0E2A3B stub and header, pass stock #F4F6F8 ground with white panels, hairline #D5DDE3, saffron #E8A33D for time only (reading line, playback line), teal-green #1F6F5C for done. Condensed numerals for codes and counts. Perforated edge under every stub. Fixed size ramp on the map: letter discs large, landmark squares small. States carry printed marks.
STORY: the learner sees which map, its tier and question count, reads the questions, hears the first listen straight through, and knows when it ends.
FIRST VIEWPORT: header; stub with MAP 01, tier, questions, mode; perforation; unofficial label; pinned status strip (countdown or playback with saffron line, Start now in guided); full-width map; question list below. Desktop: map main column, status and questions side column.
